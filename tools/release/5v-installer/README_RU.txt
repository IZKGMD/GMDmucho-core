MUCHOCORE · УСТАНОВЩИК ДЛЯ 5V.PL
=================================

Этот релиз предназначен только для сайтов https://name.5v.pl.
Версия PHP 7 на 5v.pl устарела. Установка НЕ гарантирует
полную совместимость с Geometry Dash 2.209.

УСТАНОВКА ДЛЯ НОВИЧКА
1. Создай сайт name.5v.pl и пустую MySQL-базу в панели 5v.pl.
2. Распакуй ВЕСЬ архив MuchoCore-PHP7-5v-native-preview.zip.
3. Установи Python 3.10+ (если его нет) с python.org.
4. На Windows открой START_INSTALL_WINDOWS.cmd,
   на Linux/Mac выполни sh START_INSTALL_LINUX.sh.
5. Введи домен, FTP и MySQL-данные, придумай логин/email/пароль
   первого владельца. Секреты остаются на твоём компьютере,
   а к самому сайту передаются по FTPS/HTTPS (если выбран FTPS).
6. Установщик сам находит папку сайта, загружает mc/,
   защищает конфиг, создаёт первого владельца, мигрирует
   базу и добавляет маршруты, сохраняя предыдущий .htaccess.
7. Админка: https://name.5v.pl/mc/admin.php

Рекомендуется FTPS. При выборе обычного FTP пароль FTP и
загружаемые данные НЕ шифруются! Этот выбор требует явного
подтверждения; безопасное соединение не отключается автоматически.

ЕСЛИ ЗАБЫЛ ПАРОЛЬ АДМИНКИ ИЛИ ПОТЕРЯЛ 2FA
1. НЕ переустанавливай ядро поверх существующих файлов!
2. Запусти START_RECOVERY_WINDOWS.cmd (Windows) или
   sh START_RECOVERY_LINUX.sh.
3. Подтверди владение своим сайтом через FTP и задай новый пароль.
   Если владелец один, его логин можно оставить пустым: установщик
   определит единственного активного владельца самостоятельно.
   При нескольких владельцах введи логин нужного аккаунта.
4. Временный серверный обработчик сам удаляется после сброса,
   а установщик удаляет его через FTP при любом результате.
5. Аккаунты, уровни, права владельца и данные не удаляются.
   Старые сессии, passkey и коды 2FA отзываются. После входа
   снова включи 2FA и сохрани новые коды восстановления.

Для восстановления нужен доступ к FTP своего сайта. Сохрани
данные 5v.pl в менеджере паролей, даже если забудешь админку.

ЗАЩИТА ОТ ПОТЕРИ АДМИНКИ
- Если существует mc/, автоматическая новая установка ОТКАЗЫВАЕТ,
  чтобы не стереть базу, владельца или секретные ключи.
- Никакие таблицы, аккаунты, уровни и сейвы не удаляются при
  восстановлении пароля.
- Пользователь и база MySQL должны существовать до установки;
  установщик не имеет API для создания аккаунта на 5v.pl.
- При неудаче сохраняй mc/ и отчёт muchocore-install-report.json.
  Не удаляй ничего вручную для «чистого» повторного запуска.

Адреса других хостингов отклоняются. Центральный VPS
muchogdps.space не получает FTP, MySQL или admin-пароли.
