MUCHOCORE · УСТАНОВЩИК ДЛЯ 5V.PL
=================================

Этот релиз предназначен только для сайтов https://name.5v.pl.
Версия PHP 7 на 5v.pl устарела. Установка НЕ гарантирует
полную совместимость с Geometry Dash 2.209.

УСТАНОВКА ДЛЯ НОВИЧКА
1. Создай сайт name.5v.pl и ПУСТУЮ MySQL-базу в панели 5v.pl.
2. Windows: скачай отдельный файл MuchoCore-Setup.exe из Assets
   релиза MuchoCore и запусти двойным щелчком. Python не нужен.
   Этот EXE уже содержит проверенный PHP7 payload, мастер настройки
   и патчер клиента. Он предназначен ТОЛЬКО для 5v.pl.
3. В мастере укажи адрес сайта, FTP-хост/логин/пароль,
   имя и логин пустой MySQL-базы, e-mail и пароль владельца.
   Логин владельца по умолчанию admin. FTP-хост и уникальный логин
   можно посмотреть в панели 5v.pl по значку рядом с сайтом:
   https://5v.pl/pomoc,pytanie,serwer-ftp-zapomnialem-nazwy-hosta-lub-moj-unikalny-login.html
4. Нажми «Установить MuchoCore». FTPS, поиск папки сайта и
   MySQL localhost:3306 используются автоматически. При нестандартных
   данных открой «Дополнительные настройки». Обычный FTP не включается
   без отдельного предупреждения и согласия.
5. Установщик проверит домен, FTPS и доступ к сайту, загрузит mc/,
   проверит защиту config/, создаст владельца, выполнит миграцию
   и добавит маршруты с резервной копией существующего .htaccess.
6. Если EXE найден в папке Steam или рядом с мастером, он может быть
   пропатчен локально автоматически. APK/EXE публикуются на сайте
   только при отдельном подтверждении прав на распространение.
7. Админка: https://name.5v.pl/mc/admin.php

Если нужен исходный ZIP вместо самостоятельного EXE:
распакуй весь архив, установи Python 3.10+ и запусти
START_GUI_WINDOWS.cmd. Для терминального режима есть
START_INSTALL_WINDOWS.cmd.

Рекомендуется FTPS. При выборе обычного FTP пароль FTP и
загружаемые данные НЕ шифруются! Этот выбор требует явного
подтверждения; безопасное соединение не отключается автоматически.

АВТОМАТИЧЕСКИЕ EXE / APK И ССЫЛКИ НА СКАЧИВАНИЕ
-------------------------------------------------
После установки ядра программа САМА ищет оригинальные
GeometryDash.exe и GeometryDash.apk рядом со скриптом или в папке
original_clients. На Windows также проверяет стандартную папку
Steam/steamapps/common/Geometry Dash. Если файла нет, этап
пропускается БЕЗ вопросов; позже можно запустить START_CLIENTS_WINDOWS.cmd.
При нескольких файлах или нестандартном расположении путь
указывается в отдельном мастере подготовки клиентов.
Исходные игровые файлы в релиз MuchoCore НЕ входят.

Windows EXE: безопасный патч фиксированных API-URL локальным
SHA-проверенным Python-патчером (GD 2.209); сам EXE не меняет
размер. Для запуска нужны соответствующие DLL и Resources игры.

Android APK: оригинальный APK передаётся через защищённые
небольшие HTTPS-части в клиентский патчер PHP 7, который уже
встроен в MuchoCore. Результат подписывается схемами v1 и v2
индивидуальным ключом именно твоего GDPS. Этот ключ хранится
в приватном mc/config/php7-apk-signer.json. ОБЯЗАТЕЛЬНО сделай
его резервную копию! Иначе будущие обновления APK, возможно,
не смогут устанавливаться поверх текущей сборки.
Для крупных APK понадобится свободное место на хостинге.

При наличии права на ПУБЛИЧНОЕ распространение бинарников
программа запросит отдельное подтверждение, загрузит готовые
клиенты через FTP/FTPS и выдаст прямые ссылки:
https://name.5v.pl/mc/public/clients/GeometryDash-MuchoCore-<hash>.exe
https://name.5v.pl/mc/public/clients/GeometryDash-MuchoCore-<hash>.apk
Страница ссылок: https://name.5v.pl/mc/public/clients/

Важно: владение личной копией игры НЕ даёт права публично
раздавать полные EXE/APK. Без разрешения правообладателя
публичная загрузка отключена, но локальный EXE можно
пропатчить для себя; APK можно готовить в закрытой админке.

Чтобы позднее заменить/добавить клиента, запусти
START_CLIENTS_WINDOWS.cmd (Windows) или
sh START_CLIENTS_LINUX.sh (Linux/Mac). Никаких переустановок
ядра или сбросов админки для этого НЕ нужно.

ЕСЛИ ЗАБЫЛ ПАРОЛЬ АДМИНКИ ИЛИ ПОТЕРЯЛ 2FA
1. НЕ переустанавливай ядро поверх существующих файлов!
2. Запусти тот же MuchoCore-Setup.exe и нажми
   «Восстановить админку». Python и MySQL-пароль не нужны.
   Если используешь исходный ZIP, можно запустить
   START_RECOVERY_WINDOWS.cmd (требует Python 3.10+).
3. Подтверди владение своим сайтом через FTPS, при нескольких
   владельцах укажи логин нужного владельца и задай новый пароль.
   Если владелец один, его логин можно оставить пустым: установщик
   определит единственного активного владельца самостоятельно.
   При нескольких владельцах введи логин нужного аккаунта.
4. Временный серверный обработчик сам удаляется после сброса,
   а установщик удаляет его через FTP при любом результате.
5. Аккаунты, уровни, права владельца и данные не удаляются.
   Старые сессии, passkey и коды 2FA отзываются. После входа
   снова включи 2FA и сохрани новые коды восстановления.

Для восстановления нужен доступ к FTP своего сайта. Сохрани
данные 5v.pl в менеджере паролей, даже если забудешь админку.

ЗАЩИТА ОТ ПОТЕРИ АДМИНКИ
- Если существует mc/, автоматическая новая установка ОТКАЗЫВАЕТ,
  чтобы не стереть базу, владельца или секретные ключи.
- Никакие таблицы, аккаунты, уровни и сейвы не удаляются при
  восстановлении пароля.
- Пользователь и база MySQL должны существовать до установки;
  установщик не имеет API для создания аккаунта на 5v.pl.
- При неудаче сохраняй mc/ и отчёт muchocore-install-report.json.
  Не удаляй ничего вручную для «чистого» повторного запуска.

Адреса других хостингов отклоняются. Центральный VPS
muchogdps.space не получает FTP, MySQL или admin-пароли.
