# Windows — патчер в 2 клика

**Запуск:** `START-WINDOWS.cmd`.

Нужны Windows и Python 3. Если Python не установлен, установите Python 3 с официального сайта и включите его в PATH (проверьте `py -3 --version` в терминале).

1. Запустите `START-WINDOWS.cmd`; появится окно **MuchoCore Client Patcher**.
2. Нажмите **Browse...** и выберите *оригинальный* `GeometryDash.exe`. Можно также перетащить EXE на `START-WINDOWS.cmd`, тогда путь подставится автоматически.
3. В **Server URL** укажите только адрес собственного GDPS, например `https://your-gdps.example`, **без** `/mc`, `/database`, `/a`.
4. Нажмите **Patch client**. Патчер вызовет проверенный `tools/client/client-patch.py`.
5. Рядом с оригиналом появятся пропатченный EXE и текстовый отчёт с SHA-256. Запускайте **новый** EXE из папки, где находятся ресурсы оригинальной игры.

## Что поддерживается

- GD 2.209 Windows x64: известные оригинальные сборки 13 октября (111 маршрутов) и 19 октября 2026 года (113 маршрутов); **точная** проверка SHA-256.
- Более старые клиенты: консервативная замена известных встроенных строк с проверкой результата.
- Новый EXE создаётся отдельно, оригинальный не перезаписывается.

## Если ошибка

| Сообщение | Что делать |
| --- | --- |
| `Python 3 was not found` | Установить Python 3; проверить `py -3 --version` |
| `Unknown GD 2.209 build` | Нужен оригинальный поддерживаемый EXE, не другой уже пропатченный клиент |
| `domain too long` | Использовать короткий HTTPS-домен или алиас |
| Уровни ищутся, но не открываются | Проверить функции самого GDPS и серверные маршруты, а не перепатчивать EXE |

**Для 5v.pl:** у клиента могут использоваться пути `/a/getGJLevels21.php` и `/checkIfServerOnline.php`. Проверьте [маршрутизацию shared hosting](../shared-hosting/README.md). Экспериментальный PHP 7-порт не равен полному MuchoCore.

**Альтернатива без Python:** в **полноценной** админке MuchoCore есть готовый веб-патчер Windows: `https://ВАШ-ДОМЕН/admin/?page=clientpatcher`. На PHP 7 (5v.pl) эта админка не доступна.
