Geometry Dash legacy client for Windows

1. Install BlueStacks 5 App Player and create a Nougat 32-bit instance.
2. Extract this ZIP. Run "Start-GD.cmd -Setup" once from the extracted folder.
   Drag GeometryDash-MuchoCore.apk from Explorer into the BlueStacks window.
3. Double-click Start-GD.cmd to open the game directly. In BlueStacks press
   F11 to enter fullscreen.

If you created a second instance, use its internal name, for example:
  Start-GD.cmd -Setup -Instance Nougat32_1
  Start-GD.cmd -Instance Nougat32_1

Use a dedicated instance for the patched game. Android does not install
this APK over another copy of Geometry Dash signed with a different key.

Build.txt identifies the GD version and architecture. ARM-only builds
depend on BlueStacks' ARM translation. Windows or emulator audio issues
can also affect the original APK. The Android APK is intended for legacy
32-bit Android devices and compatible emulators.
