# MuchoCore v1.0.1 — maintenance changes

> Maintainer: **IZKGMD**

This page documents the maintenance changes made after the original v1.0.1 release was published.

## Security

- Cloud Save backup now authenticates the account before writing data.
- Cloud Save sync now authenticates the account before reading data.
- A request cannot use one account ID with another account's credentials.
- Regression tests cover mismatched Cloud Save credentials.

## Database and roles

- Fixed the admin account editor to use `accounts.role_id`.
- Fixed player/profile/user queries to resolve role names through the canonical `roles` table.
- Fixed comment queries that still used the old role column.
- Added migration `20260920_002_role_schema.php`.
- The migration converts legacy role values to the canonical role IDs and removes the duplicate legacy role column.
- The legacy `helper` role is mapped to `moderator`.

## Documentation

- Added `docs/SIMPLE_STRUCTURE.md` with a beginner-friendly project map.
- README now explains which folder to open for each kind of problem.
- README now recommends **VPS** for a real public GDPS.
- Shared hosting remains supported for testing and smaller installations.

## Testing

- GitHub Actions validation passes on the current maintenance branch.
- Regression coverage was expanded for Cloud Save authentication and the role schema.

## Important release note

The existing GitHub release **v1.0.1** was originally published by `github-actions[bot]` and currently points to an earlier commit. The maintenance changes above are kept in the maintenance branch/PR and should be included in the next release after the PR is merged.

The published `mucho-core.zip` asset remains the original v1.0.1 archive until a new release asset is published.
