MUCHOCORE SHARED — УСТАНОВКА ИЗ ОДНОГО ZIP

Это полный пакет MuchoCore для хостингов с PHP 8.2+ и MySQL/MariaDB.
Docker, VPS, SSH и Composer на хостинге не нужны.

1. Создай обычный PHP-сайт в панели хостинга. НЕ псевдоним и НЕ редирект.
2. В настройках сайта выбери PHP 8.2 или новее (лучше 8.3+).
3. В панели хостинга создай ПУСТУЮ MySQL/MariaDB-базу и пользователя.
4. Распакуй этот ZIP на компьютере. Внутри находится папка muchocore/.
5. Загрузи через FTP СОДЕРЖИМОЕ папки muchocore/ непосредственно
   в веб-корень сайта — так, чтобы там оказались public/, src/,
   vendor/, database/, .htaccess, composer.json и т.д.
   ВАЖНО: проверь, что FTP-клиент загрузил скрытый .htaccess.
6. Открой https://ТВОЙ-ДОМЕН/install.php — без /public/.
   Если PHP/расширения несовместимы, получишь понятный список причин.
7. На совместимом PHP установщик откроет форму базы данных и админа.
   Вводи пароли ТОЛЬКО через HTTPS; не присылай их в чат.
8. После завершения проверь /health (ответ 1), /admin/
   и запросы настоящего клиента Geometry Dash.
9. После установки удали public/install.php и public/shared-install.php,
   сохрани .env и config/cloudsave.key, сделай резервную копию.

ДЛЯ 5V.PL И PHP 7:
Этот ZIP НЕ УСТАНАВЛИВАЕТ ПОЛНОЕ ЯДРО на PHP 7. На нём /install.php
покажет несовместимость. Нельзя «исправить» это сменой версии в Composer:
ядро и некоторые зависимости используют PHP 8. Нужен отдельный
проверенный порт кода и защиты, который пока НЕ завершён.
Уже существующий 5v-edge.php только пересылает запросы на сервер с
PHP 8.2+, он не является самостоятельным GDPS.
