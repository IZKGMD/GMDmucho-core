# Original administrator interface on native PHP 7

The native panel now renders mirrors of the actual `public/admin` templates rather than an independently designed replacement. Run `python3 tools/release/sync-php7-admin-ui.py` after changing upstream templates. The source SHA-256 manifest is `compat/php7/admin-ui/upstream-sources.json`.

The native ZIP copies the original product, admin, simple, polish, language and theme styles and GD images without modifying their bytes. The compiler extracts the original inline base styles; it lowers incompatible PHP syntax and adapts the installation mount in the product/audit scripts. The host bridge preserves the original layout with CSP nonces rather than permitting arbitrary inline scripts. Sign-out remains a CSRF-protected POST.

Original templates render the dashboard, players, levels/moderation, Rating Studio, songs, comments, messages, audit, branding settings, News Board, Administrators, roles and Database Backup Center. News supports the original image/video editor and SQL storage. Authenticator/recovery flows use native sessions; passkeys are still pending.

The additive administrator registry imports existing game administrators once, preserving their IDs, current sessions, factors and audit history. Linked accounts keep their current game password. Newly invited administrators are separate panel identities: creation does not register a game account or grant a game role. Invitations contain a hashed, single-use setup secret valid for 24 hours; the raw link appears once. Game role changes and panel role assignments are separate after this import. Disabling an administrator or changing their role advances the authentication revision, invalidating existing sessions. Permission checks apply to direct POSTs as well as displayed controls. Custom roles are serialized with assignments/deletion; built-in roles and the active owner are protected.

Database Backup Center preserves the original shared-host layout. PHP creates private, compressed, consistent-snapshot SQL backups and SHA-256 sidecars; downloads require current permission and a matching checksum. Its storage is beneath the blocked config directory. Automated scheduling, retention, server-side deletion and restore are not claimed on shared hosting. Restore uses the hosting database tool, matching the original shared-host restriction. A disposable MariaDB test restores a generated archive and verifies administrator records, views and binary bytes.

Clans, packs, plugins, client patching and VPS operations are not made available by this UI change. This is not full PHP8 backend parity and must not be described as a complete 1:1 administrator port.

The form adapter handles original account/profile/password/rating/level/music contracts with the existing native role checks and owner protection. Branding, maintenance and registration switches are persisted locally. PHP7-compatible template rendering, escaping, Plain mode, original-source hashes and form authorization/rollback are covered by `tests/compat/php7-native-original-admin.php`. Its in-memory SQLite adapter strips MySQL row-lock syntax; it does not certify MySQL concurrency. Existing real-MySQL native feature tests remain necessary in CI. Uploaded MP3s require the host's normal HTTP upload limits and a writable `public/assets/music` directory.
