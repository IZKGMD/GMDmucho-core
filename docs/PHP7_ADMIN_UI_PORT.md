# Original administrator interface on native PHP 7

The native panel now renders mirrors of the actual `public/admin` templates rather than an independently designed replacement. Run `python3 tools/release/sync-php7-admin-ui.py` after changing upstream templates. The source SHA-256 manifest is `compat/php7/admin-ui/upstream-sources.json`.

The native ZIP copies the original product, admin, simple, polish, language and theme styles and GD images without modifying their bytes. The compiler extracts the original inline base styles; it lowers incompatible PHP syntax and adapts the installation mount in the product/audit scripts. The host bridge preserves the original layout with CSP nonces rather than permitting arbitrary inline scripts. Sign-out remains a CSRF-protected POST.

Original templates currently render the dashboard, players, levels/moderation, Rating Studio, songs, comments, messages, audit and branding settings. The native account bootstrap and game feature settings remain native. Password login is supported; VPS passkey/TOTP administration is not implemented by this adapter. News still uses the native text/link editor, without the original media editor. Clans, packs, plugins, client patching and VPS operations are not made available by this UI change. This is not full PHP8 backend parity and must not be described as a complete 1:1 administrator port.

The form adapter handles original account/profile/password/rating/level/music contracts with the existing native role checks and owner protection. Branding, maintenance and registration switches are persisted locally. PHP7-compatible template rendering, escaping, Plain mode, original-source hashes and form authorization/rollback are covered by `tests/compat/php7-native-original-admin.php`. Its in-memory SQLite adapter strips MySQL row-lock syntax; it does not certify MySQL concurrency. Existing real-MySQL native feature tests remain necessary in CI. Uploaded MP3s require the host's normal HTTP upload limits and a writable `public/assets/music` directory.
