# MuchoCore: карта репозитория

Главное правило проекта:

> **Сначала сделай понятным. Потом сделай мощным.**

Новичку не нужно изучать весь код.

## Куда смотреть

| Путь | Для чего |
| --- | --- |
| `START_HERE.md` | первый запуск |
| `install.sh` | установка VPS |
| `bin/mucho` | главные команды |
| `bin/mucho-doctor` | диагностика |
| `docs/` | инструкции |
| `public/` | HTTP-входы и GD endpoint'ы |
| `src/` | основная бизнес-логика |
| `database/migrations/` | структура БД |
| `tests/` | автоматические проверки |
| `tools/` | патчеры и разработческие утилиты |
| `docker/` | контейнеры и веб-сервер |

## Что новичку обычно не нужно менять

Не редактируй `src/`, `database/` или `docker/` только ради настройки своего сервера.

Сначала используй:

```bash
bash bin/mucho doctor
```

Настройки установки находятся в `.env` и секретах, созданных установщиком.

## Как устроен запрос Geometry Dash

```text
Geometry Dash client
        ↓
public/index.php
        ↓
src/Routing/Router.php
        ↓
Controller
        ↓
Service
        ↓
Repository
        ↓
MariaDB
```

Это позволяет исправлять протокол в одном месте, не копируя один и тот же PHP-файл для каждой версии клиента.

## Как устроена совместимость

Совместимость с разными поколениями GD проходит через:

- нормализацию пути в `Router`;
- `ClientVersion` и выбор credential;
- отдельные protocol encoders;
- тесты legacy aliases и контрактов.

Cvolton/GMDprivateServer используется как поведенческий эталон протокола. Исходный код этого GPL-3.0 проекта не копируется в MuchoCore.

## Правило для новых функций

Новая функция должна по возможности иметь:

1. отдельный сервис/репозиторий;
2. миграцию БД;
3. автоматический тест;
4. понятное место в админке;
5. короткую инструкцию для новичка.

## Быстрый цикл разработчика

```bash
composer install
php tests/client-compatibility.php
php tests/router-compatibility.php
php tests/cvolton-compatibility.php
php tests/security-regression.php
```

После изменения серверной логики сначала запускай тесты, а уже потом проверяй реальный клиент.
