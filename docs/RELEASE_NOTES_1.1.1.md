# MuchoCore 1.1.1 — READY TO DEPLOY (PHP 8)

MuchoCore 1.1.1 packages the extensive core, administration, compatibility and deployment improvements since v1.1.0 into an installable PHP 8 release.

## What's included
- Pinned stable-release VPS installation instead of a moving development branch.
- A PHP 8.2+ shared-hosting ZIP with Composer dependencies, ZIP integrity checks and SHA-256 checksums.
- Admin first-owner registration, browser session checks, email recovery and security hardening backed by integration tests.
- GD 2.209 server flows for social features, messages, notifications, levels and music; automated native-request emulation and authenticated HTTP replay.
- Database migrations, Cloud Save fixes, updater recovery, administration and monitoring enhancements.

## Install (PHP 8 only)
For a VPS, point your domain at the server, then run:

```bash
curl -fsSL https://raw.githubusercontent.com/IZKGMD/GMDmucho-core/main/install-remote.sh | sudo bash
```

On shared hosting with PHP 8.2+ and MySQL, download `MuchoCore-v1.1.1-shared-hosting.zip` from [release assets](https://github.com/IZKGMD/GMDmucho-core/releases/tag/v1.1.1), upload the **contents** of `muchocore/` into the hosting directory, create an empty MySQL database, and open `/install.php`.

Do **not** use GitHub's autogenerated Source code ZIP as a ready-to-install shared-hosting package.

## Update
Back up the database, configuration and `cloudsave.key` first. On VPS run `sudo mucho update` and `sudo mucho doctor`. On shared hosting follow [SHARED_HOSTING.md](SHARED_HOSTING.md). Never run the fresh installer over existing production data.

## Verified scope and limitations
- Publishing requires PHP 8.3 + MariaDB + Caddy HTTP acceptance for the **exact** validated commit, plus Validate and archive/checksum integrity checks.
- The route inventory contains 166 entries; the separate full endpoint-certification gate has **not** passed. Automated emulation does not certify every real Geometry Dash client or device.
- No new native PHP7 archive is published as part of 1.1.1. The 5v.pl/PHP7 port will be synchronized and tested separately.
- Android patching cannot be guaranteed for arbitrary APK/ABI combinations.
- Successful hosting setup still requires a domain, database and a client patched for the server URL.
