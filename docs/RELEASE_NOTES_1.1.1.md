# MuchoCore 1.1.1 — Installable PHP 8 Preview

**Release channel:** prerelease / public preview. Installs on PHP 8.2+; **not a certified stable release**. This preview includes the extensive core, administration and GD 2.209 HTTP improvements since 1.1.0.

## Download and install

Use [v1.1.1 Preview assets](https://github.com/IZKGMD/GMDmucho-core/releases/tag/v1.1.1) **once the release is published**:

- `MuchoCore-v1.1.1-shared-hosting.zip` — PHP8 shared hosting, including Composer dependencies
- `MuchoCore-v1.1.1.zip` — tagged source snapshot for operators and auditing; not a ready-to-upload shared-hosting package
- `checksums.sha256` — integrity verification

**VPS Ubuntu with your domain:** Run the pinned preview installer (a plain installer without `--ref` selects the last *stable* release instead):

```bash
curl -fsSL https://raw.githubusercontent.com/IZKGMD/GMDmucho-core/main/install-remote.sh | sudo bash -s -- --ref=v1.1.1
```

**Shared hosting (PHP 8.2+ and MySQL):** Download `MuchoCore-v1.1.1-shared-hosting.zip`. Upload the **contents** of the `muchocore/` folder to your site, create an empty MySQL database, and open `https://YOUR-DOMAIN/install.php`. Follow [SHARED_HOSTING.md](SHARED_HOSTING.md).

Do **not** use the autogenerated GitHub Source code ZIP for shared hosting. Do not use the PHP8 archive on a PHP7-only host.

## Included since 1.1.0

- First-admin setup, browser sessions, email recovery, admin access and safety checks
- GD 2.209 levels, message and notification integration work with automated HTTP replay and endpoint emulation
- More reliable database migrations, Cloud Save, updater recovery, administration and monitoring

## Scope and evidence

The preview publication requires the Validate CI suite, **PHP8.3 + MariaDB + Caddy HTTP acceptance at exactly the release commit**, plus installable ZIP verification and SHA-256 checksums.

**Important:** The route inventory has 166 entries and full endpoint certification has not passed. Automated request emulation is not the same as complete real-device verification. Not all Android APK patcher variants are validated.

New installs are the primary acceptance target. Existing production servers should back up database/configuration/cloudsave.key and follow the update guide after testing on a copy. Normal `sudo mucho update` follows stable releases; it does not automatically opt into this preview.

**PHP7/5v.pl is not included in v1.1.1.** We will port proven changes separately, with a narrow diff and PHP7-specific tests.
