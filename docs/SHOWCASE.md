# 🌍 MuchoCore Showcase

Built a GDPS with MuchoCore? Add it to the community showcase.

The showcase is for real public or private projects using MuchoCore. Keep entries factual and link to the project when possible.

## How to submit

Open a new **MuchoCore Showcase** issue and provide:

- GDPS name;
- supported Geometry Dash version(s);
- public website or invite link, if available;
- repository or project page, if available;
- a short description of what you built;
- optional screenshot/logo.

Do not publish private credentials, server IP addresses, database dumps, tokens, API keys, or other secrets.

## Example entry

~~~text
GDPS: ExampleGDPS
Versions: GD 2.2
Website: https://example.com
Repository: https://github.com/example/example-gdps

A community GDPS powered by MuchoCore with custom levels, player profiles and a themed administration panel.
~~~

## Powered by MuchoCore

Public projects are encouraged to use a simple attribution such as:

> Powered by [MuchoCore](https://github.com/IZKGMD/GMDmucho-core) 🛡️

You can place this in your project README, website footer, documentation, or credits.

## Community contributions

Useful additions are welcome:

- documentation improvements;
- compatibility fixes;
- security hardening;
- performance work;
- tests;
- translations for non-project-facing community material;
- deployment improvements.

For protocol or security reports, use the repository's normal issue/reporting channels and avoid posting sensitive exploit details publicly.
