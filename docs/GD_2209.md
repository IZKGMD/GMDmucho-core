## Deployment (VPS)

1. Apply/merge this branch and update the PHP project.
2. Upload **your legally obtained, unmodified** GD 2.209 EXE to
   `/opt/mucho-core/storage/client-sources/GeometryDash-2.209.exe`.
   This is an untracked persistent location; do **not** replace the legacy
   repository-tracked `GeometryDash.exe`.
3. Confirm the SHA-256 matches the exact-build hash above.
4. Call the normal Windows patcher, or the normal client pack builder if you
   also have a base Android APK (the pack builder still requires it).
5. Run `php tests/client/gd-2209-synthetic.php`.

The Windows patcher detects the exact build by its SHA-256 and delegates to
`Gd2209Binary`. Unknown Windows builds retain legacy behavior.

## MuchoClient / Geode

`clients/geode/muchoclient/mod.json` still targets GD 2.2081. Its existing
Geode binaries must not be renamed or forced to load into 2.209. Wait for
validated Geode bindings, update mod metadata, rebuild and test the mod on
the actual new game executable before distributing a `.geode` file.
