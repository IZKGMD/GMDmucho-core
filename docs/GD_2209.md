**Status: core gameplay URL routing patched; live-client functionality not yet verified.**

## Quick install on an Ubuntu VPS

1. Point your domain's `A` record to the VPS IPv4 address and allow inbound TCP ports `80` and `443`.
2. Connect by SSH with a user that can run `sudo` and start the installer:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/IZKGMD/GMDmucho-core/main/install-remote.sh | sudo bash
   ```

3. Enter your domain, server name and administrator credentials when prompted. Sign in at `https://YOUR-DOMAIN/admin/` and check that `https://YOUR-DOMAIN/health` returns `1`. Then follow the [client setup guide](CLIENT_SETUP.md) to connect your game.

The installer selects the latest published stable release. For an existing VPS installation, see the [update instructions](VPS_INSTALL_QUICK.md#update-an-existing-server).

## Admin web patcher

In the authenticated admin interface, open `/admin/?page=clientpatcher`.
Enter your own GDPS HTTPS **root** (not `/database`), upload your legally obtained
unmodified `GeometryDash.exe`, and download `GeometryDash-MuchoCore.exe`.
The PHP web flow automatically uses the same exact-build `Gd2209Binary` patcher
for either known 2.209 Windows SHA-256. It checks the URL replacement count
(112 for 13 Oct or 114 for 19 Oct) before writing the output. The original
uploaded file is removed from the temporary server storage after processing.
Unknown 2.209-like EXEs fail closed instead of falling back to older fixed URL
heuristics. **No native client connectivity is certified by byte checks.**

## Deployment (VPS)

1. Apply/merge this branch and update the PHP project.
2. Upload **your legally obtained, unmodified** GD 2.209 EXE to
   `/opt/mucho-core/storage/client-sources/GeometryDash-2.209.exe`.
   This is an untracked persistent location; do **not** replace the legacy
   repository-tracked `GeometryDash.exe`.
3. Confirm the SHA-256 matches one of the two exact-build hashes above.
4. Call the normal Windows patcher, or the normal client pack builder if you
   also have a base Android APK (the pack builder still requires it).
5. Run `php tests/client/gd-2209-synthetic.php`.

The Windows patcher detects the exact build by its SHA-256 and delegates to
`Gd2209Binary`. Unknown Windows builds retain legacy behavior.

## MuchoClient / Geode

`clients/geode/muchoclient/mod.json` still targets GD 2.2081. Its existing
Geode binaries must not be renamed or forced to load into 2.209. Wait for
validated Geode bindings, update mod metadata, rebuild and test the mod on
the actual new game executable before distributing a `.geode` file.
