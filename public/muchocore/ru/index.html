Нативные запросы клиента

Geometry Dash обращается к PHP-эндпоинтам с учётом версии игры. Сервер обрабатывает реальные данные.

Пример запроса
POST /database/getGJLevels21.php
Обработка
Маршрут → сервисы → MariaDB
Возможности
Аккаунты, уровни, рекорды, общение

Схема обработки запроса, не интерактивный API-тестер.

ПУТЬ ЗАПРОСА

От игры до базы данных.

Маршруты разбирают запросы с учётом версии клиента. Сервисы применяют правила, MariaDB хранит данные. Слои разделены, чтобы обновления не превращались в заплатки.

БЕЗ ЛИШНИХ ОБЕЩАНИЙ

Совместимость подтверждают тесты.

Для Geometry Dash 1.0–2.2 описаны профили протокола, но возможности зависят от версии игры. Проверка GD 2.209 продолжается; полная совместимость на настоящем клиенте ещё независимо не подтверждена.

ВОПРОСЫ

Что важно знать.

MuchoCore действительно бесплатный?

Да. Код опубликован по лицензии MIT. Сервер, домен и дополнительные услуги могут стоить денег.

Geometry Dash 2.209 уже полностью поддерживается?

Полная совместимость ещё не подтверждена независимыми сквозными тестами. Перед переносом проверь список поддерживаемых функций.

Можно перенести существующий GDPS?

В репозитории есть документация по миграции, включая сценарий для Cvolton. Сначала сделай бэкап и проверь перенос на копии базы.
