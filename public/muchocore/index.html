05 / GOOD TO KNOW

A few straight answers.

Is MuchoCore actually free?

Yes. The source code is available under the MIT license. Your VPS, domain or other hosting services may still cost money.

Is GD 2.209 fully supported?

Compatibility work is active, but some endpoints still need real-client testing. Check the compatibility page and repository release notes before migrating.

Can I migrate a Cvolton server?

MuchoCore includes a Cvolton-oriented migration kit. Make a backup and test the import on a database copy before switching your live server.

Can I write my own plugins?

Yes. Custom plugin routes and lifecycle hooks are documented. Review third-party plugin source before installing it on your server.
