07 / FAQ

Questions worth answering.

What exactly is MuchoCore?

An open-source server-side backend for Geometry Dash private servers. It handles game requests and provides tools to operate player accounts, content and server administration.

Which Geometry Dash versions are supported?

Documented runtime profiles cover GD 1.0, 1.1, 1.5, 1.9, 2.0, 2.1 and 2.2. Individual GD 2.209 features still require real-client verification.

Can I migrate an existing Cvolton GDPS?

There are preflight checks, ID mapping and migration tools for Cvolton-based databases. Always test the migration on a database copy first.

Can I build custom plugins?

Yes. Custom plugins live in custom/plugins/ and can register routes and lifecycle hooks. Third-party PHP plugins are executable server-side code, so inspect them before installation.

How do I deploy MuchoCore?

The recommended VPS setup uses Docker Compose, PHP, MariaDB and Caddy. Compatible shared hosting has a separate installation workflow.
