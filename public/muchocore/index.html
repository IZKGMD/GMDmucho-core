02 / REQUEST FLOW

From the game to your database.

Client requests are parsed by version-aware routes; application services apply the rules; MariaDB stores persistent state. Keep the layers distinct so updates do not turn into patches.

03 / REAL COMPATIBILITY

Version support is measured, not guessed.

MuchoCore documents Geometry Dash 1.0–2.2 protocol profiles. Individual features depend on the client generation. Work on GD 2.209 continues; complete real-client coverage has not been independently verified.

05 / QUESTIONS

Before you start.

Is MuchoCore free?

Yes. The code is published under the MIT license. Hosting, domains and other services can still cost money.

Is Geometry Dash 2.209 fully supported?

Not yet independently verified end to end. Read the feature-by-feature compatibility notes before migrating a server.

Can I migrate an existing GDPS?

The repository includes migration documentation, including a Cvolton-oriented path. Back up your database and test a copy first.
