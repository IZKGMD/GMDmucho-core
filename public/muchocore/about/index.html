MuchoCore / Official project information

What is MuchoCore?

MuchoCore is an open-source, self-hosted Geometry Dash Private Server (GDPS) core written in PHP. It is the server-side software used to operate a private Geometry Dash community: accounts, user profiles, levels, scores, moderation and related game endpoints.

Its canonical source repository is IZKGMD/GMDmucho-core. The names MuchoCore and GMDmucho-core refer to the same project. MuchoGDPS is the separately named public GDPS community/site, not another name for the server framework itself.

What can you build with MuchoCore?

Run a GDPS

Host account registration, profiles, levels, comments, ratings, scores, music and cloud-save-related services through a shared PHP server application.

Manage a community

Use role-based admin workflows for accounts, moderation, level ratings, maintenance, diagnostics, and backups.

Move an existing server

The Migration Kit includes Cvolton-oriented source checks and mapped data migration. Validate with a database backup first.

Develop extensions

A PHP plugin system supports custom routes and lifecycle hooks. MuchoClient is a separate Geode-side integration for additional in-game features.

How is MuchoCore different from Geometry Dash or Geode?

Geometry Dash is the game. Geode is an independently developed mod loader for the game client. MuchoCore provides server-side infrastructure. MuchoClient, where installed, adds features inside the game and communicates with MuchoCore. A GDPS is a private community using its own compatible endpoints and data.

A game version being listed in a compatibility profile does not prove that every feature is tested against the original executable. For detailed version and validation status, read the compatibility overview and the client compatibility documentation.

How to start

  1. Read the Getting Started guide and setup instructions.
  2. Choose a deployment environment and configure the database, application secrets and domain.
  3. Install and verify the server, configure a compatible client, and test registration, levels, backups and permissions.
  4. Follow updates and security advisories in GitHub Releases.
