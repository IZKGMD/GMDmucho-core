MuchoCore installation

Choose your hosting.

Use the installation path that matches your hosting. Shared hosting is the no-VPS option for compatible PHP hosts. VPS is the full-server option with Docker, Caddy and automatic or manual deployment.

⇩

Shared hosting / FTP

For hosts such as Beget or InfinityFree, when the account provides the PHP, database, HTTPS and filesystem features required by MuchoCore.

No VPS, Docker or SSH
Upload one file by FTP / File Manager
Verified stable release download
Browser database and admin setup
Dedicated public IPv4 is not required

VPS

For Linux VPS servers where you want full control, Docker-based deployment, Caddy HTTPS and the complete MuchoCore operator stack.

Dedicated public IPv4 required for direct HTTPS
Automatic browser deployment available
One-command SSH installation
Docker + Caddy + MariaDB setup
Health checks, migrations and operator tools
View VPS installation guide →
Not sure which path you need? Use Shared Hosting when you only have FTP/file-manager access. Use VPS when you have root/sudo access and a dedicated public IPv4 for the standard direct-HTTPS deployment.

Both paths include a step-by-step onboarding page. The shared-hosting path uses the dedicated /ftp-install.php bootstrap; the VPS path can use the web deployment gateway or the official SSH installer.
