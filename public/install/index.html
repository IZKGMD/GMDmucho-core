VPS · Automated
AUTOMATED

Automatic VPS setup

Connect a Linux VPS and follow the guided deployment. Requires SSH root access, dedicated public IPv4 and inbound HTTP/HTTPS ports.

  • Docker Compose, PHP and MariaDB
  • Caddy for HTTP and HTTPS
  • Logs and deployment verification

VPS · Manual
MANUAL

Manual VPS installation

Run the official installer yourself and review each step. Best for operators who prefer SSH and full control over configuration.

  • Linux VPS with root or sudo
  • Review project scripts before executing
  • Configure domain, database and secrets

5v.pl shared hosting

Dedicated native PHP 7 preview upload for 5v.pl subdomains only. Database and owner setup are completed in your own browser; game compatibility is not certified.

  • Domain name.5v.pl and FTP access
  • Fresh mc/ installation directory
  • PHP 7 is obsolete; expect provider limits
5v.pl setup ↗

VPS: direct public setup requires a dedicated IPv4 address and TCP 80/443. The admin interface uses HTTPS.

Shared hosting: free-tier restrictions may prevent some game requests even when PHP works. Verify provider limits first.
