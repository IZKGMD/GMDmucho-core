VPS / Linux

Install MuchoCore on your VPS.

Use this page for a normal Linux VPS deployment. You can start an automatic browser deployment or run the official installer yourself over SSH. Both paths use the same MuchoCore release and production checks.

Required: a dedicated public IPv4 address.

The standard MuchoCore VPS deployment expects a VPS with its own public IPv4 that accepts inbound TCP 80 and 443. Point your GDPS domain directly to that IPv4. NAT/CGNAT VPS products without public inbound 80/443 are not suitable for the normal direct-HTTPS path; use the documented Cloudflare Tunnel mode instead.

Before you start

Linux VPS with root or sudo access
Dedicated public IPv4 assigned to the VPS
TCP 80 and 443 reachable from the Internet
A domain or subdomain for the GDPS
Ability to create an A record for that hostname
An initial MuchoCore Admin Panel password

Network layout

For the standard direct deployment, the public hostname should resolve straight to the dedicated VPS IPv4.

GDPS domain ↓ DNS A record ↓ Dedicated VPS IPv4 ↓ TCP 80 / 443 ↓ Caddy ↓ MuchoCore
01

Point your domain to the VPS

Create an A record for the hostname you want to use for the GDPS.

gdps.example.com → YOUR_DEDICATED_VPS_IPV4

Wait for DNS to resolve before starting the installer. The direct deployment uses Caddy to obtain and manage HTTPS certificates.

02

Choose automatic or manual installation

Automatic deployment connects to the VPS from MuchoGDPS and shows live installer output. Manual installation runs the same official release bootstrap directly inside your VPS over SSH.

Start automatic VPS deployment → Show manual command ↓
03

Run the stable installer over SSH

Connect to the VPS as root or as a sudo-capable user, then run:

curl -fsSL https://raw.githubusercontent.com/IZKGMD/GMDmucho-core/main/install-remote.sh | sudo bash

The installer asks for the GDPS domain and initial administrator password, installs Docker and the production stack when needed, applies migrations, configures Caddy and verifies the public health endpoint.

04

Verify the server

After the installer finishes, open the public health endpoint:

https://gdps.example.com/health

Expected response:

1

Then open the Admin Panel:

https://gdps.example.com/admin/
05

Patch and connect your Geometry Dash client

Open the Admin Panel client patcher and generate the client patch for your supported Geometry Dash version. Then test account login, level search, level upload and Cloud Save from a real client.

06

Migrate an existing GDPS

Install MuchoCore against a fresh target database first. Then use Admin → Tools → Migration Center or the Migration Kit. Do not use your legacy GDPS database as the initial MuchoCore target.

Migration guide ↗ Getting Started ↗

Updates

Production updates use published stable GitHub releases. The usual operator command is sudo /opt/mucho-core/update.sh.

When direct VPS HTTPS is unavailable

If your provider does not give the VPS a dedicated public IPv4 or does not pass inbound 80/443, the normal direct path cannot receive public traffic. MuchoCore supports an explicit Cloudflare Tunnel transport for that infrastructure.

This page documents the standard VPS deployment. Shared hosting does not require a dedicated public IPv4: use /install/shared/ instead. Full operator documentation is maintained in the MuchoCore repository.
