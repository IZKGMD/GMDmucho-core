FTP / file manager

Install MuchoCore without a VPS.

Use any compatible PHP shared host. Upload one small bootstrap file with FTP, open it in your browser, and MuchoCore will download the latest published shared-hosting package, verify its SHA-256 digest, unpack it, and open the normal database installer.

FTP credentials stay with your hosting provider.

MuchoGDPS does not need your FTP hostname, username or password. FTP is only the way you put the bootstrap file into your hosting account.

01

Create a fresh site folder

Use a dedicated folder or document root for the GDPS. The bootstrap intentionally refuses to overwrite an existing application or .htaccess file.

02

Download the one-file FTP bootstrap

Download the bootstrap, then upload ftp-install.php into that fresh web directory with FTP or the hosting file manager.

Download ftp-install.php ↗ View source ↗
03

Open the bootstrap over HTTPS

Visit the uploaded file in a browser:

https://YOUR-DOMAIN/ftp-install.php

The preflight checks PHP 8.3+, ZIP support, SHA-256 hashing, secure randomness, outbound HTTPS and writable storage.

04

Start the verified installation

The bootstrap resolves the latest published stable GitHub release, finds its shared-hosting package, verifies the release digest before extraction, and hands off to /shared-install.php.

05

Enter the database and admin settings

The normal shared-hosting installer creates the schema, verifies database permissions, creates a backup, runs migrations, bootstraps the administrator and verifies the final installation.

Shared hosting still needs PHP 8.3+, PDO MySQL, HTTPS and a MySQL 8.0.29+ or MariaDB 10.4+ database. Docker, SSH, sudo and Composer are not required for this installation path. See the full shared-hosting guide for migration and operational limitations.
