FTP / FTPS deployment

Install MuchoCore on shared hosting.

MuchoGDPS can connect to a compatible shared-hosting account itself, upload the verified MuchoCore release over FTP or FTPS, start the built-in shared installer, and verify the result. You do not need SSH or a hosting terminal.

How automatic shared hosting deployment works

Your browser sends the FTP and database credentials to the MuchoGDPS deployment service over HTTPS. The service uses them only for this deployment job, does not write them to deployment logs, and deletes them when the job finishes.

01

Prepare the shared-hosting account

Create the domain/site and an empty MySQL/MariaDB database. MuchoCore will not overwrite a non-MuchoCore database.

02

Find your FTP values

In the hosting control panel, find the FTP hostname, FTP username, FTP password, port, and the directory that serves the domain.

FTP host · username · password · port · remote directory
03

Enter the public GDPS URL

The target website must already have a valid HTTPS certificate because the deployment service starts the remote installer over HTTPS.

https://gdps.example.com
04

Start automatic deployment

MuchoGDPS downloads the latest published stable shared-hosting package, verifies its SHA-256 digest, uploads it through FTP/FTPS, runs the shared installer and checks /health.

05

Open your GDPS

When the console reports success, open your GDPS and Admin Panel. The remote shared installer removes itself when possible.

https://gdps.example.com/healthhttps://gdps.example.com/admin/
Shared hosting does not require a dedicated public IPv4. The provider must still allow normal public HTTP/API requests from Geometry Dash clients. Some free hosting providers may pass PHP preflight checks but block game/app traffic.
