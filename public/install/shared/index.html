Установить MuchoCore
на 5V.PL

Отдельный установщик для бесплатного 5v.pl. Он загружает PHP 7-совместимую сборку по FTP; базу данных и владельца ты настроишь непосредственно на своём сайте.

ТОЛЬКО 5V.PLДругие хостинги отклоняются

01. Твой GDPS

Сначала создай сайт на 5v.pl и получи доступ к FTP. Адрес должен оканчиваться строго на .5v.pl.

Только HTTPS и домен вида name.5v.pl, без /mc, /database и путей.

02. FTP-подключение

Адрес FTP, логин и пароль 5v.pl присылает на почту при регистрации. Вводи данные только здесь, по HTTPS.

Дополнительные настройки FTP
Автоопределение через временный маркер; для нестандартного FTP-каталога можно указать путь вручную.
Далее откроется консоль загрузки

Как пройдёт установка

  1. 1
    Проверка 5V.PLСервер отклонит адрес любого другого хостинга.
  2. 2
    PHP 7 nativeСоберём отдельную PHP 7-совместимую версию, а не PHP 8-архив.
  3. 3
    Загрузка по FTPФайлы попадут в mc/. Существующая установка не перезаписывается.
  4. 4
    Приватный конфиг и браузерСоздай пустую базу MySQL в панели 5v.pl. После загрузки появится кнопка «Открыть мастер настройки админки» — в ней укажи данные MySQL и придумай пароль. Никаких PHP-файлов вручную менять не нужно.
  5. 5
    Правила и тестДобавь правила из 5V_ROOT_REWRITE_RULES.txt в корневой .htaccess, проверь клиент GD.

Ограничения 5V.PL

Это PHP 7 preview, не PHP 8. PHP 7 устарел и не получает обычных исправлений безопасности. Совместимость всех функций Geometry Dash 2.209 на реальном клиенте пока не подтверждена.

Данные базы остаются в приватном конфиге на 5v.pl, а первый владелец создаётся на твоём сайте. Мы не перезаписываем существующий .htaccess и не объявляем загрузку полноценной установкой до ручной настройки.
