What happens automatically

01Verify releaseDownload the latest stable shared-hosting package and verify SHA-256.
02Auto-detect connectionTry FTP/FTPS and common ports, then authenticate and enable passive mode.
03Auto-detect web rootFind the public directory and verify it over HTTPS.
04UploadTransfer the verified MuchoCore package into the shared host.
05InstallRun the remote shared installer with your database settings.
06VerifyCheck /health and finish the deployment job.

Credential handling

FTP, database and admin credentials are sent over HTTPS to MuchoGDPS, kept only in the temporary deployment job, never printed in the installation log, and removed after the job exits.

Provider compatibility

The automatic flow is universal, but the hosting provider must allow FTP/FTPS, PHP execution and the database setup required by MuchoCore. Provider-specific free-tier traffic restrictions can still prevent a working GDPS client connection after installation.
